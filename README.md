# Neon Founder ID

MVP приложения для Windows-киоска: анкета на 5 вопросов для студентов, расчет
предпринимательского профиля, съемка или загрузка фото и вставка головы участника
в готовый шаблон результата.

## Запуск

```bash
pnpm install
pnpm dev
```

После запуска:

- интерфейс: `http://localhost:5173`
- API обработки фото: `http://localhost:8787`
- готовые изображения: `public/results`
- базовые шаблоны для обработки: `public/templates`

## Нейросетевой режим

Backend умеет отправлять шаблон и портрет в OpenAI Image Edit. Модель получает строгий
промпт: менять только область головы, сохранить композицию, текст, логотип и одежду, а
лицо подогнать по ракурсу, масштабу, свету и цвету.

1. Скопируйте `.env.example` в `.env`.
2. Заполните `OPENAI_API_KEY` на машине киоска или на защищенном сервере.
3. Запустите `pnpm dev`.

Если ключ отсутствует или внешний запрос завершился ошибкой, API автоматически использует
локальную сборку через Sharp. GitHub Pages остается статическим демо и работает через
canvas-fallback: ключ в браузер и в репозиторий не попадает.

Ключ, опубликованный в чате, следует отозвать и выпустить заново перед использованием.
Фото студентов являются персональными данными: заранее получите согласие на обработку и
не храните результаты дольше необходимого.

## Режим киоска

Для установки на Windows:

1. Включить автозапуск приложения.
2. Открывать `http://localhost:5173` в полноэкранном браузере или Electron shell.
3. Запретить системные жесты и выход из окна.
4. Настроить очистку `public/results` и временных фото по расписанию.
